TANNAY & SRUSHTI — ROYAL WEDDING INVITATION

FILES
- index.html: complete responsive wedding invitation website
- palace-doors.mp4: supplied palace entrance video
- palace-poster.jpg: extracted first-frame poster for the entrance screen

PREVIEW LOCALLY
1. Keep all three files in the same folder.
2. Double-click index.html, or open it in Chrome/Edge/Safari.
3. Tap “Tap to Enter”. The supplied video plays, then the invitation appears.

PUBLISHING
Upload all three files together to a static hosting service (for example GitHub Pages, Netlify, or your own web hosting). Do not upload index.html alone; it needs the MP4 and poster image beside it.

IMPORTANT NOTES
- The background instrumental is an original, soft ambient melody generated in the browser after the visitor taps to enter. Browsers require a user gesture before audio can start.
- Countdown target: 11 February 2027, 9:00 PM India Standard Time.
- Google Maps button uses the exact location link supplied by the couple.
- RSVP currently shows a confirmation only on the visitor's device. It does not send or collect submissions. Connect a form service/backend before publishing if you need to receive guest responses.
- Event dress codes are shown as “To be announced” where none were supplied.
